# SPEC-RECEIPT-003 인수 기준 (Acceptance Criteria)

## Given-When-Then 시나리오

### 시나리오 1: 상세 페이지 진입

**시나리오**: 사용자가 영수증 목록에서 특정 영수증을 선택하여 상세 페이지로 이동

#### Given (전제 조건)
- 사용자가 로그인된 상태
- 영수증 목록 화면(`ReceiptListPage`)에 있음
- 최소 1개 이상의 영수증이 존재

#### When (액션)
- 사용자가 특정 `ReceiptCard`를 탭

#### Then (예상 결과)
- `ReceiptDetailPage`로 이동
- 선택한 영수증의 전체 크기 이미지가 표시됨
- 모든 정보가 정확히 표시됨:
  - 금액 (통화 형식: ₩12,346)
  - 날짜 (yyyy-MM-dd 형식)
  - 카테고리 (ShadBadge)
  - 업무 목적 (전체 텍스트)
  - 제출 상태 (초록색 "제출됨" 또는 주황색 "대기중")
  - 생성일 (yyyy-MM-dd HH:mm)

---

### 시나리오 2: 영수증 수정 (제출 전)

**시나리오**: 사용자가 제출되지 않은 영수증을 수정

#### Given (전제 조건)
- 사용자가 `ReceiptDetailPage`에 있음
- 영수증이 제출되지 않은 상태 (`isSubmitted: false`)
- "수정" 버튼이 활성화되어 있음

#### When (액션)
- 사용자가 "수정" 버튼을 탭

#### Then (예상 결과)
- 수정 화면으로 이동 (ReceiptUploadPage 재사용)
- 모든 입력 필드에 기존 정보가 채워져 있음:
  - 금액 필드
  - 카테고리 드롭다운
  - 날짜 선택기
  - 업무 목적 입력란
  - 기존 이미지 미리보기

#### When (추가 액션)
- 사용자가 필드를 수정하고 "저장" 버튼을 탭

#### Then (예상 결과)
- Firestore가 업데이트됨
- 성공 메시지 표시: "영수증이 수정되었습니다"
- 상세 화면으로 자동 복귀
- 수정된 정보가 반영되어 표시됨

---

### 시나리오 3: 영수증 삭제 (제출 전)

**시나리오**: 사용자가 제출되지 않은 영수증을 삭제

#### Given (전제 조건)
- 사용자가 `ReceiptDetailPage`에 있음
- 영수증이 제출되지 않은 상태 (`isSubmitted: false`)
- "삭제" 버튼이 활성화되어 있음

#### When (액션)
- 사용자가 "삭제" 버튼을 탭

#### Then (예상 결과)
- 확인 다이얼로그가 표시됨:
  - 제목: "영수증 삭제"
  - 메시지: "정말로 이 영수증을 삭제하시겠습니까? 이 작업은 취소할 수 없습니다."
  - 버튼: "취소", "삭제" (빨간색)

#### When (추가 액션)
- 사용자가 "삭제" 버튼을 탭

#### Then (예상 결과)
- Firebase Storage에서 이미지 삭제됨
- Firestore에서 문서 삭제됨
- 성공 메시지 표시: "영수증이 삭제되었습니다"
- 영수증 목록 화면으로 자동 복귀
- 삭제된 영수증이 목록에서 사라짐

---

### 시나리오 4: 영수증 제출

**시나리오**: 사용자가 영수증을 제출하여 최종 확정

#### Given (전제 조건)
- 사용자가 `ReceiptDetailPage`에 있음
- 영수증이 제출되지 않은 상태 (`isSubmitted: false`)
- "제출" 버튼이 활성화되어 있음

#### When (액션)
- 사용자가 "제출" 버튼을 탭

#### Then (예상 결과)
- 확인 다이얼로그가 표시됨:
  - 제목: "영수증 제출"
  - 메시지: "영수증을 제출하시겠습니까? 제출 후에는 수정 및 삭제가 불가능합니다."
  - 버튼: "취소", "제출"

#### When (추가 액션)
- 사용자가 "제출" 버튼을 탭

#### Then (예상 결과)
- Firestore `isSubmitted` 필드가 `true`로 업데이트됨
- 성공 메시지 표시: "영수증이 제출되었습니다"
- 화면이 자동으로 갱신됨:
  - 제출 상태 배지: 주황색 "대기중" → 초록색 "제출됨"
  - 수정/삭제/제출 버튼이 사라지거나 비활성화됨
  - 안내 메시지 표시: "이미 제출된 영수증입니다. 수정 및 삭제가 불가능합니다."

---

### 시나리오 5: 제출된 영수증 보기

**시나리오**: 사용자가 이미 제출된 영수증을 조회

#### Given (전제 조건)
- 사용자가 로그인된 상태
- 영수증 목록 화면에 있음
- 제출된 영수증 (`isSubmitted: true`)이 1개 이상 존재

#### When (액션)
- 사용자가 제출된 영수증의 `ReceiptCard`를 탭

#### Then (예상 결과)
- `ReceiptDetailPage`로 이동
- 모든 정보가 정상적으로 표시됨
- 제출 상태 배지: 초록색 "제출됨"
- 수정/삭제/제출 버튼이 표시되지 않거나 비활성화됨
- 안내 메시지 표시: "이미 제출된 영수증입니다. 수정 및 삭제가 불가능합니다."

---

### 시나리오 6: 삭제 취소

**시나리오**: 사용자가 삭제 확인 다이얼로그에서 취소를 선택

#### Given (전제 조건)
- 사용자가 `ReceiptDetailPage`에 있음
- 삭제 확인 다이얼로그가 표시됨

#### When (액션)
- 사용자가 "취소" 버튼을 탭

#### Then (예상 결과)
- 다이얼로그가 닫힘
- 영수증이 삭제되지 않음
- 상세 화면으로 복귀

---

### 시나리오 7: 제출 취소

**시나리오**: 사용자가 제출 확인 다이얼로그에서 취소를 선택

#### Given (전제 조건)
- 사용자가 `ReceiptDetailPage`에 있음
- 제출 확인 다이얼로그가 표시됨

#### When (액션)
- 사용자가 "취소" 버튼을 탭

#### Then (예상 결과)
- 다이얼로그가 닫힘
- `isSubmitted` 상태가 변경되지 않음 (여전히 `false`)
- 상세 화면으로 복귀
- 수정/삭제/제출 버튼이 여전히 활성화되어 있음

---

### 시나리오 8: 네트워크 오류 처리

**시나리오**: 네트워크 오류로 인해 작업이 실패

#### Given (전제 조건)
- 사용자가 `ReceiptDetailPage`에 있음
- 네트워크 연결이 불안정하거나 끊김

#### When (액션)
- 사용자가 "수정" 또는 "삭제" 또는 "제출" 버튼을 탭하고 확인

#### Then (예상 결과)
- 에러 메시지가 ShadToast로 표시됨:
  - 수정 실패: "수정 실패: [에러 메시지]"
  - 삭제 실패: "삭제 실패: [에러 메시지]"
  - 제출 실패: "제출 실패: [에러 메시지]"
- 작업이 취소됨
- 버튼이 다시 활성화됨 (재시도 가능)

---

### 시나리오 9: 이미지 로딩 중

**시나리오**: 큰 이미지 파일 로딩 시 로딩 상태 표시

#### Given (전제 조건)
- 사용자가 `ReceiptDetailPage`로 이동 중
- 영수증 이미지가 큰 파일 (3MB 이상)

#### When (액션)
- 페이지가 로드되고 이미지를 다운로드 중

#### Then (예상 결과)
- 이미지 영역에 `CircularProgressIndicator` 표시
- 이미지 로드 완료 시 전체 크기 이미지가 표시됨
- 이미지 로드 실패 시 에러 아이콘 및 메시지 표시

---

### 시나리오 10: Firestore 보안 규칙 검증

**시나리오**: 제출된 영수증을 수정하려고 시도

#### Given (전제 조건)
- 사용자가 `ReceiptDetailPage`에 있음
- 영수증이 이미 제출됨 (`isSubmitted: true`)
- 클라이언트 측 검증을 우회하여 직접 Firestore 업데이트 시도

#### When (액션)
- Firestore API 직접 호출로 업데이트 시도

#### Then (예상 결과)
- Firestore 보안 규칙에 의해 요청이 거부됨
- `FirebaseException: permission-denied` 에러 발생
- 클라이언트에서 적절한 에러 메시지 표시

## 비기능 요구사항 인수 기준

### 성능
- [ ] 상세 페이지 초기 로딩 시간: 1초 이내
- [ ] 이미지 로딩 시간: 3MB 기준 3초 이내
- [ ] Firestore 업데이트 응답: 500ms 이내
- [ ] 삭제 작업 완료: Storage + Firestore 삭제 합산 2초 이내

### 보안
- [ ] Firestore 보안 규칙: 제출된 영수증 (`isSubmitted: true`) 수정/삭제 시도 시 거부
- [ ] 사용자 인증: 로그인되지 않은 사용자는 페이지 접근 불가 (GoRouter redirect)
- [ ] 권한 검증: 다른 사용자의 영수증 접근 시도 시 거부

### 사용성
- [ ] 모든 확인 다이얼로그는 명확한 메시지와 버튼 제공
- [ ] 에러 메시지는 ShadToast로 3초간 표시
- [ ] 성공 메시지는 ShadToast로 2초간 표시
- [ ] 로딩 상태는 CircularProgressIndicator로 명확히 표시
- [ ] 제출된 영수증은 수정 불가 안내 메시지 제공

### 접근성
- [ ] 모든 버튼에 Semantic Label 추가
- [ ] 색상 대비 WCAG AA 기준 준수
- [ ] 스크린 리더 지원
- [ ] 키보드 네비게이션 지원
